## When to Use
Use for procedural relay/ruin asset improvements, not as an AAA acceptance shortcut.

## Procedure
1. Capture the existing stable relay-close or relay-overview camera before changing source. Preserve normal-route and release-preview distinctions.
2. Build per-material SurfaceTools using immutable MachinedPrimitives rounded meshes and exact convex collision. Preserve catalog identity and verify envelope, standing route and factory ray parity.
3. Generate original local PBR maps with the existing Pillow environment, deterministic RNG and a hash/license manifest. Check ORM channels, normal unit error and byte-identical regeneration.
4. Run isolated headless editor import before runtime preload/capture of newly generated textures. A capture marker and exit0 with missing-preload errors are invalid.
5. View actual native-resolution output; iterate on overly contrasty or overly smooth material response without changing global light or graphics quality to conceal it.
6. Run smoke_relay_art, smoke_signal_ring_art, smoke_relay_approach, full factory parity, normal input route, native/fallback suites, package audit and actual isolated release GPU preview before a source-only commit.

## Pitfalls
- The factory merges each material, not every decorative part into separate draws; collision shapes may remain individual.
- The existing concrete_cast texture has high-contrast aggregate discs; replacing it globally prematurely would alter unreviewed interiors.
- Pillow's getdata is deprecated in the installed environment; get_flattened_data is available.
- An old package file count is not a schema: compare actual PACKAGE_FILE additions/removals and separately verify embedded textures by rendering.

## Verification
1. All relevant logs are diagnostic-free with successful markers and exit codes.
2. Actual before/after camera and native resolution match; residual wall, wear, contact and temporal issues remain disclosed.
3. Scoped Git checkpoint preserves baseline/private-source hashes and excludes raw evidence/releases/saves.
